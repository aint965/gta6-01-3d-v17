Palkon Auto is a GTA-style 3D open-world game set in Solmar — 637 buildings, 7 districts, 4 drivable cars, live traffic obeying a 26-second light cycle — rendered with handwritten WebGL 2, no engine and no libraries. Drive Mara Venn through four missions worth $2,000, watch the HEAT wanted system bring Solmar PD's patrol cars after you, and keep SOLMAR FM's three original loops playing while the sun sets over the boulevard.

## Run it
```sh
node serve.ts
```

then open http://localhost:8080
